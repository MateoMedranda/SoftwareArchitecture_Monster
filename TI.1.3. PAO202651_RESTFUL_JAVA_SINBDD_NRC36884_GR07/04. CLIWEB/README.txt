Cliente web MVC para el servicio RESTful de conversiones.

Proyecto NetBeans/Maven: CLIENTE_WEB

Requiere que el servidor REST este desplegado en:
http://127.0.0.1:9080/CONV_REST_JAVA/api

Para usar otra direccion, configure antes de iniciar Payara:
- Propiedad JVM: -Dmonster.rest.base-url=http://HOST:PUERTO/CONV_REST_JAVA/api
- Variable de entorno: MONSTER_REST_BASE_URL

Credenciales de prueba: MONSTER / MONSTER9
