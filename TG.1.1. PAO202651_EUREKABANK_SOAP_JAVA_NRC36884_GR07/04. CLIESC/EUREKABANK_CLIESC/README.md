# Cliente de escritorio EUREKABANK

Aplicación Java 17/Swing con MVC. Ejecute `mvn compile exec:java`. El servidor se toma de `EUREKABANK_URL` o de `http://localhost:9080`.

Logo PNG: copie su archivo a `src/main/resources/img/logo.png` antes de compilar. La interfaz tiene respaldo visual si aún no se ha colocado.
